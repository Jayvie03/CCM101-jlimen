# Automation Research – The Language of Automation

## 1. Bash Script 

A Bash script is a file that contains a series of Linux commands that can be executed together to perform specific tasks automatically. The `#!/bin/bash` line, also called the shebang, tells the operating system that the file should be executed using the Bash shell interpreter. It ensures that the commands written in the script are understood and executed correctly using Bash.

## 2. Variables

Variables are used to store information that can be reused throughout a script. For example, `$BACKUP_DIR` stores the name or path of the backup directory, making the script easier to maintain because the value can be changed in one place instead of repeatedly editing multiple commands.

## 3. Cron Job

A Cron job is a Linux feature that allows commands or scripts to run automatically at scheduled times. It is important in cloud operations because it helps automate repetitive tasks, such as backups and maintenance, without requiring someone to execute them manually.
