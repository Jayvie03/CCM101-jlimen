# Cloud Provider Comparison

## AWS, Microsoft Azure, and Google Cloud

The three major public cloud providers offer similar infrastructure services, although the services have different names and features.

| Infrastructure Component             | AWS        | Microsoft Azure                 | Google Cloud Platform       |
| ------------------------------------ | ---------- | ------------------------------- | --------------------------- |
| Compute                              | Amazon EC2 | Azure Virtual Machines          | Compute Engine              |
| Storage                              | Amazon S3  | Azure Blob Storage              | Cloud Storage               |
| Networking                           | Amazon VPC | Azure Virtual Network           | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM    | Microsoft Entra ID / Azure RBAC | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

The three major cloud providers offer a very broad range of services for computing, storage, networking, databases, security, artificial intelligence, and other cloud workloads. The exact range can change over time, so the comparison should be based on the current official documentation.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a strong choice for an organization that primarily uses Microsoft products. Azure provides services designed to work with Microsoft's ecosystem and identity solutions.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its AI and machine learning capabilities and also provides managed Kubernetes through Google Kubernetes Engine (GKE).

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer similar fundamental infrastructure services, including compute, storage, networking, and identity and access management. They allow organizations to provision resources through cloud platforms instead of maintaining all infrastructure on physical servers.
