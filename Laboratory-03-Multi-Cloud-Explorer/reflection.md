# Mission Reflection

Completing Mission 3, “Become a Multi-Cloud Explorer,” helped me understand that choosing a cloud platform is not simply about selecting the most popular provider. Each platform has different strengths, services, and features that can be useful depending on the needs of an organization.

Among AWS, Microsoft Azure, and Google Cloud Platform, the platform that impressed me the most was Microsoft Azure. I found Azure particularly interesting because of its strong integration with Microsoft technologies and its wide range of services for enterprise environments. However, I also learned that AWS and Google Cloud have important strengths, especially in the areas of broad cloud services, artificial intelligence, data analytics, and Kubernetes.

AWS, Azure, and GCP have many similarities. All three provide cloud computing, storage, networking, identity management, databases, security services, and scalable infrastructure. They also provide global infrastructure and management consoles that allow users to create and manage cloud resources. These similarities make it possible for organizations to find equivalent services across different cloud providers.

Business requirements strongly influence cloud platform selection. A company should consider its budget, existing technologies, workload requirements, security needs, scalability, location of users, and technical skills. For example, a company that already uses Microsoft technologies may benefit from Azure, while an AI-focused organization may consider Google Cloud.

Acting as a Cloud Solutions Consultant taught me to look at technical decisions from a business perspective. Instead of choosing a provider based only on popularity, I learned to match the provider's services with the client's specific requirements.

This mission improved my GitHub Cloud Computing Portfolio by adding organized research, comparison tables, recommendations, Linux investigation results, screenshots, and Markdown documentation. It also helped me improve my ability to organize technical information and present it in a professional way.
