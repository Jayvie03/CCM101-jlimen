# Reflection - The Cloud Automation Engineer

Throughout Laboratory Activities 1 to 9, I gained knowledge and practical experience in different areas of Cloud Computing. These activities helped me understand how cloud environments are created, managed, monitored, and secured. Laboratory 09, in particular, taught me the importance of automation when managing cloud systems.

Automation is important when managing hundreds of cloud servers because it saves time, reduces repetitive tasks, and minimizes human errors. Instead of performing the same tasks manually on every server, administrators can use scripts to complete them more efficiently. However, automation also has potential dangers. For example, a script containing a destructive command or an incorrect instruction could affect hundreds or even thousands of servers if executed without proper checking. This is why scripts should always be reviewed and tested before being used.

In Laboratory 09, I learned how to create a Bash script to automate the backup process using Linux commands. This experience was different from Laboratory 06, where I used Docker Compose to deploy a multi-tier application. Bash scripts are used to automate commands and tasks, while Docker Compose is used to define and manage application services and containers. Both tools are useful for managing cloud environments and making administrative tasks easier.

Looking back at Laboratory Activities 1 to 9, my understanding of Cloud Computing has improved through the different practical exercises. I gained experience using Linux commands, managing files and storage, working with Docker containers, deploying applications, monitoring system resources, configuring firewalls, and automating tasks. These activities helped me understand how different tools and technologies work together in managing cloud infrastructure.

Among the different cloud engineering roles, I enjoyed the **Cloud Security Engineer** role the most because I was interested in learning how to protect servers and control network access. In Laboratory 08, I gained practical experience deploying an Nginx application using Docker and configuring UFW to protect the server. I also learned about the Attack Surface, the Principle of Least Privilege, and the importance of allowing only necessary network ports. This activity helped me understand that keeping a server running is not enough; it must also be properly secured.
