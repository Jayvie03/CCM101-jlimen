# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, artificial intelligence, analytics, and application development.

## Global Infrastructure

Azure provides a global infrastructure consisting of geographic regions and availability zones. Organizations can deploy resources in different locations to improve application availability, performance, and resilience.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources that can run operating systems and applications in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for unstructured data such as documents, images, videos, backups, and application data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks and connect cloud resources securely.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management capabilities for users, applications, and resources.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft products and technologies.
2. **Scalability** – Organizations can scale cloud resources based on their requirements.
3. **Enterprise Features** – Azure provides services for security, identity, networking, databases, analytics, and enterprise applications.

## Typical Enterprise Use Cases

Azure can be used for Windows Server workloads, Microsoft 365 environments, enterprise applications, databases, web applications, virtual desktops, data analytics, artificial intelligence, and hybrid cloud infrastructure.
