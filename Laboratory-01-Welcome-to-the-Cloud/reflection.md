# Reflection

In this laboratory activity, I learned how to access and use a cloud-based Linux environment through KillerCoda. I learned how to use the Linux terminal and perform basic commands. I also learned how to create a new Linux user, give the user a home directory, Bash shell, and sudo privileges, and then log in to the new account.I also learned how to check basic system information such as the Linux distribution, kernel version, CPU information, total memory, and available disk space. Another part of the activity was creating directories and Markdown files and organizing them properly. At first, using the Linux command line was challenging because I needed to type commands correctly. I handled this by following the instructions step by step and checking the output after each command.
This activity also helped me understand the importance of GitHub and proper documentation. I learned how to organize my laboratory files in a GitHub repository and use Markdown to document my work. Overall, this laboratory gave me a basic understanding of Linux, file management, user management, system information, GitHub, and Markdown. These skills will help me with the future Cloud Computing laboratory activities.
