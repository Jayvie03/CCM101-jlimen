# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

In this laboratory activity, I investigated the infrastructure of a Linux cloud environment using KillerCoda. I examined compute, storage, networking, and operating system resources and documented my findings.

## Objectives

* Understand the major components of cloud infrastructure.
* Investigate hardware and software resources in a Linux environment.
* Identify compute, storage, networking, and identity resources.
* Compare AWS, Microsoft Azure, and Google Cloud services.
* Create a simple cloud infrastructure diagram.
* Practice technical documentation using Markdown.

## Cloud Infrastructure Components

The main infrastructure components investigated in this laboratory were compute, storage, networking, and the operating system.

Compute resources provide processing power. Storage provides space for data and files. Networking allows resources to communicate with other systems. The operating system manages the server resources and provides an environment for applications and commands.

## Linux Commands Executed

The following Linux commands were used to investigate the operating system, compute, memory, storage, and networking resources of the cloud server.

| Command | Purpose / Short Explanation |
|---|---|
| `cat /etc/os-release` | Displays information about the Linux operating system, such as its name and version. |
| `uname -r` | Displays the Linux kernel version currently running on the system. |
| `lscpu` | Displays detailed information about the CPU, including its model, architecture, and number of cores. |
| `nproc` | Displays the number of available processing units or CPU cores. |
| `free -h` | Displays the system's RAM and memory usage in a human-readable format. |
| `lsblk` | Lists the available storage devices and their partitions. |
| `df -h` | Shows disk space usage and the available space on mounted file systems. |
| `hostname` | Displays the hostname assigned to the Linux server. |
| `hostname -I` | Displays the IP address or IP addresses assigned to the server. |
