# Laboratory Activity 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity, titled **Mission 1: Welcome to the Cloud**, introduces the basic environment, tools, and practices used in cloud computing.

The activity involves accessing a cloud-based Linux environment through KillerCoda, exploring the Linux operating system, creating and managing a Linux user, gathering basic system information, organizing files and directories, documenting technical work using Markdown, and creating a GitHub repository.

This laboratory serves as the first step in building my Cloud Computing Portfolio for CCM101.
 
## Objectives

The objectives of this laboratory activity are to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed

During this laboratory activity, I performed the following tasks:

1. Accessed the Ubuntu Linux environment through KillerCoda.
2. Verified that the Linux terminal was functioning correctly.
3. Created a new Linux user with Bash and a home directory.
4. Assigned sudo privileges to the new user.
5. Set a password for the new user.
6. Logged in to the newly created Linux account.
7. Recorded the current username, working directory, and hostname.
8. Identified the Linux distribution.
9. Checked the Linux kernel version.
10. Gathered CPU information.
11. Checked the total system memory.
12. Checked the available disk space.
13. Created the required workspace directories.
14. Created and documented the `about-me.md` file.
15. Created a GitHub repository for the Cloud Computing Portfolio.
16. Organized the laboratory files according to the required repository structure.
17. Created Markdown documentation for the laboratory activity.
18. Captured screenshots as evidence of completed tasks.
19. Committed and pushed the completed work to GitHub.

## Linux Commands Used

The following Linux commands were used during this laboratory activity:

| Command | Purpose |
|---|---|
| `whoami` | Displays the current username |
| `pwd` | Displays the current working directory |
| `hostname` | Displays the system hostname |
| `useradd` | Creates a new Linux user |
| `usermod` | Modifies a user's account settings |
| `passwd` | Creates or changes a user's password |
| `su` | Switches to another user account |
| `cat` | Displays the contents of a file |
| `uname` | Displays system and kernel information |
| `lscpu` | Displays CPU information |
| `free` | Displays memory information |
| `df` | Displays disk space information |
| `mkdir` | Creates directories |
| `cd` | Changes the current directory |
| `ls` | Lists files and directories |
| `touch` | Creates files |
| `nano` | Creates and edits text or Markdown files |
| `cp` | Copies files and directories |
| `find` | Searches for and displays files and directories |
| `git` | Used for version control and GitHub repository management |

## Skills Learned

Through this laboratory activity, I developed several foundational skills related to cloud computing and Linux administration.

First, I learned how to access and work inside a cloud-based Linux environment using KillerCoda. I also learned how to navigate the Linux file system and use basic command-line commands.

Second, I learned how to create and manage Linux users, configure user accounts, assign sudo privileges, and work with user home directories.

Third, I learned how to collect basic system information such as the Linux distribution, kernel version, CPU information, memory, and disk space.

I also improved my ability to organize files and directories and create technical documentation using Markdown.

Finally, I learned how GitHub can be used to maintain an organized portfolio of laboratory activities and technical work. This provides a foundation for future CCM101 laboratory activities throughout the semester.
